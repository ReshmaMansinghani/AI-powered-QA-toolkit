# MCP Server for Jira - QA Use Case

## Overview

This section explains how AI (via MCP) can support QA workflows integrated with Jira.

---

## What MCP Can Help With

- Read Jira user stories
- Understand acceptance criteria
- Generate test cases
- Identify missing edge cases
- Summarize defects
- Create QA status updates
- Support sprint planning

---

## Example Prompt

Read Jira story ABC-101 and generate positive, negative, and edge test cases.

---

## QA Benefits

- Faster test case creation
- Better requirement understanding
- Improved bug analysis
- Increased QA productivity

---

## Security Notes

- Do not expose Jira credentials
- Store tokens in environment variables
- Do not commit secrets to GitHub
