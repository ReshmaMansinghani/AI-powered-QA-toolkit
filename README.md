# AI Powered QA Toolkit

This repository showcases how AI can be practically used in QA workflows.

It focuses on real-world usage of AI in manual testing, API testing, and automation support — not just theory.

---

## What This Repository Covers

* Test case generation using AI
* Bug analysis and defect reporting
* API testing support
* Exploratory testing ideas
* Playwright automation support
* Jira workflow support
* MCP (Model Context Protocol) concepts for QA

---

## Why I Created This

As a QA professional, I wanted to document how AI can help in day-to-day testing activities such as:

* Understanding requirements
* Generating test cases
* Identifying edge cases
* Improving bug reports
* Supporting test planning

This repository is a collection of those practical examples.
